# 🧬 GENEJELLY
### DNA Data Storage & Genetic Algorithm Visualization Platform

An interactive futuristic web platform exploring how digital data can theoretically be encoded into DNA sequences.

[🚀 Live Website](https://sm4006.github.io/DNA-DATA-STORAGE/)

# 📖 Overview

GENEJELLY is a biotechnology-inspired web project focused on visualizing futuristic DNA-based data storage concepts through interactive animations and modern web design.

# ✨ Features

- 🧬 DNA Encoding Visualization
- ⚡ Interactive Animations
- 🧠 Genetic Algorithm Concepts
- 🌌 Futuristic UI Design
- 📱 Responsive Layout

# 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- AOS Animations
